Encoder Rotation

Action Chainモード中は、以下のRotation Value設定は実行されません。設定は保持・検証されます。

CWでPosition +1、CCWで−1。Initialは起動・Rotation Valueへの切替・Range変更時に適用されます。その他の設定変更ではCurrentを保持します。Encoder Pushは独立したPress / Releaseです。

Linked Outputs

Start / Endは昇順・降順・同値に対応。OSC Floatはfloat32に正規化します。送信は最新状態を優先し、未送信値は上書き・破棄される場合があります。

    OSC送信先

    OSC Action / Linked Outputs共通の送信先です。変更後は「保存・適用」を押してください。

    Input

    Action Chain

    登録順に実行。WaitはこのChainだけを待機させます。Press / Releaseは独立。1キーのPress / Release合計で最大16 Actions（Encoder回転は各Event最大8 Actions）。

    Key Presetは選択中のキーのPress / Release両方を含みます（Encoder Pushも対応）。Encoder回転は全体設定で保存できます。

    「実行中止・HID解除」はWait中のChainと未処理の入力・出力を破棄し、ChainPadのキーボード押下状態（修飾キーを含む）を解除します。MIDIメッセージは送信しません。保存・適用時も同じ処理を行います。

    設定ファイル Import / Export

    Exportは未保存の編集も含みます。Wi-Fi設定（SSID・パスワード）は含めず、Import時も現在のWi-Fi設定を保持します。Importは編集画面へ反映され、「保存・適用」で本体に保存します。

    Wi-Fi設定

    SSID / Passwordの変更後は「保存・適用」→「Restart」の順に押してください。
