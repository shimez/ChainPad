Encoder Rotation

Action Chainモード中は、以下のRotation Value設定は実行されません。設定は保持・検証されます。

CWでPosition +1、CCWで−1。Initialは起動・Rotation Valueへの切替・Range変更時に適用されます。その他の設定変更ではCurrentを保持します。Encoder Pushは独立したPress / Releaseです。

Linked Outputs

Start / Endは昇順・降順・同値に対応。OSC Floatはfloat32に正規化します。送信は最新状態を優先し、未送信値は上書き・破棄される場合があります。

Preview（ブラウザ上でのOutputのテスト）

エンコーダーの回転量によってOSC/MIDI出力される値を、Preview Positionを変えてブラウザ上で確認できます。

デバイスには送信せず、Current Positionも変更しません。

    Actionは登録順に実行されます。WaitはこのChainだけを待機させ、他のChainには影響を与えません。

    設定ファイル Import / Export

    Exportは未保存の編集も含みます。Wi-Fi設定（SSID・パスワード）は含めず、Import時も現在のWi-Fi設定を保持します。Importは編集画面へ反映され、「保存・適用」で本体に保存します。

    組み込みConfig

    KEY・Encoderの編集内容を置き換えます。DefaultはBLEキーボードの入力確認用、Emptyは白紙の設定です。Wi-Fi・OSC送信先は保持し、「保存・適用」までは本体へ反映しません。

    Maintenance

    「実行中止・HID解除」は実行中・未処理のChainを破棄し、キーボードの全キーを離した状態にします。

    Wi-Fi設定

    SSID / Passwordの変更後は「保存・適用」→「Restart」の順に押してください。

    Factory Reset — すべての設定を初期化

    Wi-Fi・OSC・Action・Rotation・本体のBluetoothペアリング情報を削除し、自動再起動します。Wi-Fiの再設定と、PC側のBluetooth登録解除・再ペアリングが必要です。

    WebUIが開けない場合は、Web Installerの「Erase device」を選んで再インストールしてください。
