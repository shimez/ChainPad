OSC送信先

全OSC Action共通の送信先です。変更後は「保存・適用」を押してください。

Input

Action Chain

登録順に実行。WaitはこのChainだけを待機させます。Press / Releaseは独立。最大8 Actions / Event。

Key Presetは選択中のキーのPress / Release両方を含みます（Encoder Pushも対応）。Encoder回転は全体設定で保存できます。

「実行中止・HID解除」はWait中のChainと未処理の入力・出力を破棄し、ChainPadのキーボード押下状態（修飾キーを含む）を解除します。MIDIメッセージは送信しません。保存・適用時も同じ処理を行います。

設定ファイル Import / Export

Exportは未保存の編集も含みます。全体設定にはWi-Fiパスワードも含まれます。Importは編集画面へ反映され、「保存・適用」で本体に保存します。

Wi-Fi設定

SSID / Passwordの変更後は「保存・適用」→「Restart」の順に押してください。
