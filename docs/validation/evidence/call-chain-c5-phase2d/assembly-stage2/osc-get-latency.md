# 別課題：設定GET中のOSC到着間隔（C5）

224 Action設定・208連番のPC受信では、OBS未接続／Ready時の最大到着間隔が、assembly内部配置（A＋C比較用再ビルド）で891／928 ms、PSRAM配置で912／918 msだった。全件順序一致・GET内容一致。各条件1試行であり、今回の移動による明確な回帰は認められないが、性能同等性の証明ではない。
