ChainPad

VRChat向けマルチプロトコルキーパッド

ChainPadは、1つのキー操作にOSC・MIDI・HIDなど複数のアクションを組み合わせて実行できる、12キー＋ロータリーエンコーダーのキーパッドです。

Getting Started →使い方・仕様を見る

ChainPadでできること

1つのキーで、OSC / MIDI / HIDをまとめて操作。

VRChatの演出から音楽、PCのショートカットまで。いつも使う操作を組み合わせて、手元のキーから呼び出せます。

VRChat演出

OSCを使ってカメラの設定やアバターの機能を操作。配信準備やアバター演出の切り替えを手元のキーにまとめられます。

音楽・ライブ

MIDI NoteやCCで対応する音楽ソフトや機器をコントロール。VRChatのMIDI対応ワールドの操作にも使えます。

PC操作

キーボードショートカットでOBSのシーン切り替えやマイクのミュートを操作。よく使う機能をキーに割り当て、配信中もすばやく呼び出せます。

ChainPadの特徴

🛜 OSC / 🎹 MIDI / ⌨ HID

OSCメッセージ、MIDI Note・CC、キーボード操作を一連の作業（Action Chain）に。Waitで操作の間に待機時間も挟めます。

PressとReleaseを自由に

押したとき・離したときの動作を別々に設定。1キーあたりPress/Release合計で16 Actionsまで設定できます。

アプリ不要

専用アプリケーションの導入は不要です。OSCはWiFiで直接、MIDI/HIDはBluetooth/USBデバイスとして接続しメッセージを送信します。設定はブラウザから行います。

各機能をシンプルに使いたい場合はこちら

ChainPadは、OSC・MIDI・Keyboard HIDを自由に組み合わせたい上級者向けです。各機能をシンプルに使いたい方は、用途に合ったFirmwareを選べるChainOSCPadのポータルをご覧ください。

対応ハードウェア

XIAO ESP32S3XIAO ESP32C3XIAO ESP32C6XIAO ESP32C5

現行ChainOSCPad PCBの12キー・エンコーダー・プッシュ・LEDに対応。S3はUSB / BLE MIDI・HID、C3 / C6 / C5はBLE MIDI・HIDを利用できます。OSCはWi-Fiで送信します。

Encoder Pushも合計16 Actions、Encoder回転は時計回り・反時計回りに各8 Actionsです。
