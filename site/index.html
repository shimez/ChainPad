PROJECT CHIMERA

ChainPad

ひとつのキーから、つながる操作。
OSC・MIDI・Keyboard HIDを、好きな順番で。

12キーとロータリーエンコーダーにAction Chainを設定。ブラウザで編集して、本体に保存できます。

Web Installerを開く →使い方・仕様を見る

操作を組み合わせる

🛜 OSC / 🎹 MIDI / ⌨ HID

OSCメッセージ、MIDI Note・CC、キーボード操作をひとつのChainに。Waitで操作の間に待機時間も挟めます。

PressとReleaseを自由に

押したとき・離したときの動作を別々に設定。1キーで合計16 Actionsを共有し、登録した順番で実行します。

ブラウザで設定・保存

本体のConfiguratorで編集・並べ替え。Key Presetや全体設定のImport / Exportで設定を再利用できます。

対応ハードウェア

XIAO ESP32S3XIAO ESP32C3XIAO ESP32C6XIAO ESP32C5

現行ChainOSCPad PCBの12キー・エンコーダー・プッシュ・LEDに対応。S3はUSB / BLE MIDI・HID、C3 / C6 / C5はBLE MIDI・HIDを利用できます。OSCはWi-Fiで送信します。

Encoder Pushも合計16 Actions、Encoder回転は時計回り・反時計回りに各8 Actionsです。

はじめ方

  1. Web InstallerをPCのChrome / Edgeで開き、USB接続した本体にFirmwareを書き込みます。
  2. 本体のWi-Fi ChainPad-Setup に接続します（パスワード：chimera-pad）。Wi-Fi設定画面で接続先を設定します。
  3. 同じWi-Fiから chainpad.local または本体のIPアドレスを開き、Action Chainを設定・保存します。

Configuratorは本体が配信します。AP接続のまま設定する場合は 192.168.4.1/configurator を開いてください。
