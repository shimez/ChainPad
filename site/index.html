Firmwareをインストール

PCのGoogle Chrome / Microsoft Edgeで開き、データ通信対応USBケーブルでXIAOを接続してください。接続したチップに合うFirmwareが自動選択されます。現行ChainOSCPad PCB向けです。

このブラウザはWeb Serialに対応していません。PC版ChromeまたはEdgeを使用してください。
  1. ボタンを押し、XIAOのシリアルポートを選択します。
  2. 画面の案内に従って書き込みます。
  3. 完了後、必要に応じてRESETボタンで本体を再起動します。

ポートが見つからない場合は、BOOTを押しながらUSBを接続するか、BOOTを押しながらRESETしてダウンロードモードにしてください。シリアルモニターなど、ポートを使用中のアプリは閉じてください。

「Erase device」を選ぶと保存設定も消去されます。必要な設定は書き込み前に本体の /api/config から控えてください。

書き込み後のWi-Fi設定

  1. Wi-Fi ChainPad-Setup に接続します。パスワードは chimera-pad です。
  2. ログイン通知からWi-Fi設定画面を開きます。自動表示されない場合は http://192.168.4.1/ を開きます。
  3. 接続先のSSID・パスワードを入力し「保存して再起動」を押します。
  4. 同じWi-Fiに戻り、http://chainpad.local/ または本体のIPからAction Chainを設定します。

AP接続のまま通常の設定画面を開く場合は /configurator を使用できます。S3はUSB / BLE MIDI・Keyboard、C3 / C6 / C5はBLE MIDI・Keyboardに対応します。

Firmwareのダウンロード
